# Night sleep checks

No lamp recording has been collected for this skill, and this directory is
not evidence of a lamp run. `crates/skills/tests/it/night_sleep.rs` runs one
fixture night through both routes: Expression's built-in sleep, and this
manifest in the skills engine with its rest leased to an Expression that has
its claim. It checks the settle moments, the reflex wakes, the fallback and
the claim turned off. A face replay alone cannot show the result: the skill
needs Expression's `expression/state` and its rest receipts as peers.
