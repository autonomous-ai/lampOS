---
name: bedtime-morning
description: A quiet evening, owned rest at night, and a small morning wake.
---

This installed core skill is disabled until measured on a lamp. It has no
model tool. The shared `use_skill` catalogue therefore gains no function.

At night, apply bounded light and volume ceilings without restoring an old
setting afterward. When the desk has stayed empty for fifteen minutes,
request sustained rest from Expression. At the first quiet morning arrival,
wake only rest this skill still owns, with the existing small stretch and a
quiet Say hum. Never wake a manual or privacy sleep. A physical interruption,
restart, refusal or consumed daily chance is not retried later that day.

The evening glow is one small, warm, slow breath, not a spoken announcement.
All hours, durations and ceilings in `skill.toml` are authored defaults, not
lamp measurements. See [the implementation and verification boundary](../../docs/bedtime-morning.md).
