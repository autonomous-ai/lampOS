## ART and the shas (#8437's artifact)

CI run `45258512096`, artifact `lampos-arm64-bb005c8c40491bf181033e40302cdbd70b3d9b4a` (head `bb005c8c40`). The runner
downloads it into an empty folder, e.g. `gh run download 45258512096 -R autonomous-ai/lampOS -n
lampos-arm64-bb005c8c40491bf181033e40302cdbd70b3d9b4a -D <ART>`. `<ART>` must hold `lamp-tasks`, `lamp-control`,
`lamp-skills` and `lamp-voice`, and their `SHA256SUMS`. If the artifact has no SHA256SUMS, make one with `(cd <ART> &&
shasum -a 256 lamp-tasks lamp-control lamp-skills lamp-voice > SHA256SUMS)`. Then:

```
S(){ awk -v b=$1 '$2 == b || $2 == "*"b {print $1}' <ART>/SHA256SUMS; }
E="KIT_ENV=<env> MIC_YES=yes ART=<ART> PR_TASKS_SHA=$(S lamp-tasks) PR_CONTROL_SHA=$(S lamp-control) PR_SKILLS_SHA=$(S lamp-skills) PR_VOICE_SHA=$(S lamp-voice)"
```

## The batches (each one whole run, lock to release, ≤ 20 min)

The first run renders QUICK, PEAR and TCHAT (`./run.sh render`, the lamp's relay, as before).

```
# 1. S, Y on the swap (2 asks)                                  ~13 min
env $E LEGS="S Y" SKIP="tails boot" ./run.sh
# 2. L (after), T on the swap (2 asks)                           ~14 min
env $E KEEP_VERDICTS=1 LEGS="L T" SKIP="tails boot" ./run.sh
# 3. L before: the installed stable, no swap (1 ask)             ~9 min
env KIT_ENV=<env> MIC_YES=yes KEEP_VERDICTS=1 LEGS="L" SKIP="swap tails boot" ./run.sh
```

With `swap` in `SKIP`, run.sh runs a baseline. It removes the last `logs/swap.txt`, `check` reads no PR sha and skips
#8180's cgroup checks (`CG_CHECK=0`), and `restore` writes `RESTORED OK (baseline run …)` without touching the lamp. L
then runs in `before` mode. Batch 3 can run before batch 2. Either way, each L prints the latest before and after
numbers from `row/logs/latency-L.txt`.
